# نمونه دورریختنی فضای کار فروشنده

این نمونه برای پاسخ به یک پرسش ساخته شده است: «ساده‌ترین مسیر فروشنده برای راه‌اندازی فروشگاه، ساخت کالای فیزیکی، مدیریت موجودی و انجام سفارش چیست؟»

نسخه دوم بر پایه بازخورد مستقیم طراحی شده است: رنگ اصلی `#a41439`، فونت Yekan Bakh، نئومورفیسم کنترل‌شده، اندازه‌های فشرده، حرکت‌های کوتاه و تقسیم هر کار به صفحه یا قدم مستقل.

سه رویکرد ساختاری روی یک مسیر و با `?variant=` قابل مقایسه‌اند:

- `A`: تمرکز آرام — فرم باریک و یک کار در هر صفحه
- `B`: گفت‌وگوی کوتاه — یک پرسش در هر لحظه
- `C`: پیش‌نمایش زنده — همان قدم‌ها کنار نمای خریدار

اجرا از ریشه مخزن:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run-seller-prototype.ps1
```

سپس `http://localhost:4173/?variant=A` را باز کنید. این کد محصول نیست، هیچ داده‌ای ذخیره نمی‌کند و همه اقدام‌ها شبیه‌سازی شده‌اند.

## پرسش‌های بازخورد

1. کدام شیوه ساخت کالا طبیعی‌تر است: تمرکز A، پرسش‌های B یا پیش‌نمایش C؟
2. میزان سایه‌های نئومورفیک مناسب است یا باید تخت‌تر/برجسته‌تر شود؟
3. سرعت و دامنه حرکت‌های کوتاه چطور است؟
4. خانه ساده پس از ساخت کالا به‌اندازه کافی روشن است یا حتی باید خلوت‌تر شود؟
