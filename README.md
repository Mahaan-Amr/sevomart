# SevoMart

نام کاری مخزن یک شبکه فروشگاهی اجتماعی فارسی برای فروشندگان آنلاین فعال ایران است. هر فروشنده فروشگاه مستقل و قابل شخصی‌سازی دارد؛ خریدار می‌تواند از لینک مستقیم وارد شود، کالا ببیند، فروشگاه‌ها را دنبال کند، در فید کشف گردش کند و سفارش خود را درون پلتفرم پیگیری کند.

> نام تجاری عمومی هنوز قطعی نیست. `SevoMart` در این مخزن یک نام کاری است.

## وضعیت فعلی

پروژه در مرحله تصمیم‌گیری محصول، نمونه‌سازی و آماده‌سازی مشخصات نسخه اول است. هنوز پشته فنی نهایی نشده و این مخزن عمداً کد محصول را پیش از بسته‌شدن تصمیم معماری scaffold نمی‌کند.

## اصل راهنما

دلیل وجود محصول، قابل‌اعتمادتر و قابل‌پیگیری‌تر کردن خرید از فروشندگان آنلاین است. هیچ رابط، متن یا قابلیت نباید سطح حفاظت را بیشتر از واقعیت نشان دهد.
