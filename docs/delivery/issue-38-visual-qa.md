## بررسی خودکار

- [ ] سفر کامل `Browser → Next.js → REST API → PostgreSQL` در هر چهار viewport سبز است.
- [ ] فارسی و `dir="rtl"` در مسیر فروشنده و مهمان ثابت است.
- [ ] متن کوتاه و بلند و نام طولانی بدون overflow افقی می‌شکنند.
- [ ] loading، empty، validation error، server error، success و refresh پوشش دارند.
- [ ] ظاهر پیش‌فرض و لوگو، جلد و رنگ شخصی‌سازی‌شده پوشش دارند.
- [ ] ترتیب keyboard، focus قابل دیدن و targetهای تعاملی حداقل `40px` هستند.
- [ ] کنتراست متن و اقدام‌های اصلی حداقل `4.5:1` است.
- [ ] در zoom مؤثر `200%` clipping یا overflow افقی وجود ندارد.
- [ ] `prefers-reduced-motion: reduce` حرکت غیرضروری را حذف می‌کند.
- [ ] شکست CI، HTML report، screenshot، video و trace را artifact می‌کند.
- [ ] imageهای `api`، `web` و `worker` از Dockerfileهای production build می‌شوند.
- [ ] سبز شدن تست‌ها به سرویس خارجی وابسته نیست.
