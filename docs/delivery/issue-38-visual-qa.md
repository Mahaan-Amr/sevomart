# مرور بصری پذیرش سرتاسری برش اول

این چک‌لیست artifact مرور انسانی Issue
[`[Build] پذیرش سرتاسری و Visual QA جامع برش اول`](https://github.com/Mahaan-Amr/sevomart/issues/38)
است. تصاویر قطعی زیر توسط Playwright از Chromium و بدون شبکه خارجی تولید می‌شوند.

## بررسی خودکار

- [x] سفر کامل `Browser → Next.js → REST API → PostgreSQL` در هر چهار viewport سبز است.
- [x] فارسی و `dir="rtl"` در مسیر فروشنده و مهمان ثابت است.
- [x] متن کوتاه و بلند و نام طولانی بدون overflow افقی می‌شکنند.
- [x] loading، empty، validation error، server error، success و refresh پوشش دارند.
- [x] ظاهر پیش‌فرض و لوگو، جلد و رنگ شخصی‌سازی‌شده پوشش دارند.
- [x] ترتیب keyboard، focus قابل دیدن و targetهای تعاملی حداقل `40px` هستند.
- [x] کنتراست متن و اقدام‌های اصلی حداقل `4.5:1` است.
- [x] در zoom مؤثر `200%` clipping یا overflow افقی وجود ندارد.
- [x] `prefers-reduced-motion: reduce` حرکت غیرضروری را حذف می‌کند.
- [x] شکست CI، HTML report، screenshot، video و trace را artifact می‌کند.
- [x] imageهای `api`، `web` و `worker` از Dockerfileهای production build می‌شوند.
- [x] سبز شدن تست‌ها به سرویس خارجی وابسته نیست.

راستی‌آزمایی محلی در ۲۰۲۶-۰۸-۲۰ با `pnpm test:e2e` (۷۶ تست) و
`docker compose build api web worker` انجام شد.
