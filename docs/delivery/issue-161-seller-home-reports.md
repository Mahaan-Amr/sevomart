# تحویل خانه کارمحور و گزارش پایه فروشنده

مرجع: [[ساخت] ساخت خانه کارمحور و گزارش پایه فروشنده](https://github.com/Mahaan-Amr/sevomart/issues/161)

مبنای اجرا `e63adf6e0875a166715bb20afa016a13a6a5a3a6` و predecessor migration برابر
`20260831140500__media__dispute-evidence` است. این برش migration، قرارداد، dependency،
متغیر محیطی یا پورت runtime تازه ندارد.

## رفتار فروشنده

- خانه فروشنده `GET /v1/seller/overview` را به‌عنوان projection خصوصی و store-scoped
  کارهای سفارش، آماده‌سازی معوق و اختلاف می‌خواند و فقط ردیف‌های دارای اقدام واقعی را
  نشان می‌دهد. خلاصه producer-owned گفت‌وگوی نیازمند پاسخ نیز بدون اسکن رشته‌ها باقی
  مانده است.
- موجودی، گفت‌وگو، اختلاف و گزارش فروش مقصد مستقل دارند. خانه به شبکه KPI یا مرور
  آماری تبدیل نشده است.
- `/seller/reports` گزارش خصوصی فروش، تعداد سفارش و تعداد سفارش تکمیل‌شده را برای
  بازه پیش‌فرض ۳۰ روزه همراه تاریخ دقیق ابتدا و انتها نمایش می‌دهد. نبود سفارش، empty
  state روشن دارد و شکست read به‌جای عدد ساختگی اعلام می‌شود.
- مبلغ قراردادشده IRR با formatter مشترک رابط به تومان نمایش داده می‌شود. هیچ آمار
  عمومی، قیف، CRM یا BI پیشرفته اضافه نشده است.

## راستی‌آزمایی

- acceptance test با PostgreSQL واقعی projection یک فروشگاه را می‌سازد و خانه، مسیر
  گزارش، مبلغ، سفارش‌ها، تکمیل و empty state را از رابط عمومی بررسی می‌کند.
- همان آزمون RTL، موبایل و دسکتاپ، نبود overflow، اندازه هدف‌های تعاملی، کنتراست و
  `prefers-reduced-motion` را پوشش می‌دهد.
