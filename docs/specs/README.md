# مشخصات

## مشخصات فعال

- [مشخصات محصول نسخه اول](mvp-product-spec.md) — محدوده قطعی، سفرهای خریدار و فروشنده، اعتماد، مجوزها و معیارهای پذیرش سراسری

هر spec یک رفتار قابل ساخت را پس از بسته‌شدن تصمیم‌های Wayfinder تعریف می‌کند.

حداقل ساختار:

- مسئله و کار اصلی کاربر
- محدوده و خارج از محدوده
- واژگان و نقش‌ها
- جریان اصلی و حالت‌های خطا
- stateها و transitionها
- مجوز و حریم خصوصی
- قرارداد ورودی/خروجی و رویدادها
- متن‌های حساس اعتماد و پرداخت
- معیارهای پذیرش
- تست و observability

تا زمانی که Issue تصمیم بالادستی باز است، spec وابسته باید `blocked` بماند. مشخصات محصول نسخه اول با تصمیم Issue مرجع بسته شده و مبنای ساخت است؛ جزئیات هر ماژول می‌تواند در spec کوچک‌تر و لینک‌شده ادامه پیدا کند.
