## نام تجاری

گزارش‌های بررسی نام برای حفظ تاریخچه تصمیم نگهداری می‌شوند. نتیجه آن‌ها تأیید حقوقی ثبت علامت نیست. نام کاری مخزن نباید از این اسناد به‌عنوان برند نهایی استنباط شود.
