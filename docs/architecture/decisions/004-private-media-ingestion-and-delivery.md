# ADR-004: دریافت و تحویل خصوصی رسانهٔ فروشگاه

- وضعیت: پذیرفته‌شده
- تاریخ: ۱۴۰۵-۰۵-۲۶
- مبنای کار: [مشخصات محیط کامل محلی و رسانهٔ فروشگاه](../../specs/complete-local-runtime-and-media.md)، با تأیید صریح مالک محصول در جلسهٔ تصمیم‌گیری
- استثنای فرایندی: Issue مستقل پیش از ساخت ایجاد نشد و این بدهی پیگیری باید در کار بعدی بسته شود.

## زمینه

ارسال Base64 در JSON هم سربار حافظه دارد و هم پیش از رسیدن درخواست به اعتبارسنجی رسانه با سقف
پیش‌فرض بدنهٔ Fastify و خطای `413` متوقف می‌شود. در عین حال نشان و تصویر روی جلد دارایی فروشنده‌اند؛
اصل فایل نباید افت کیفیت پیدا کند یا پیش از انتشار فروشگاه عمومی شود.

## گزینه‌ها

1. نگهداری Base64 در JSON و افزایش سقف بدنه؛ ساده، اما پرهزینه و شکننده برای فایل‌های واقعی.
2. URL عمومی MinIO؛ تحویل سبک‌تر، اما مرز حریم خصوصی و جزئیات زیرساخت را به client نشت می‌دهد.
3. multipart، اصل خصوصی، مشتق‌های محدود و تحویل از API؛ کمی بار بیشتر روی API، با مرز اعتماد پایدار.

## تصمیم

گزینهٔ سوم انتخاب شد. آپلود `multipart/form-data` هدف `STORE_LOGO` یا `STORE_COVER` دارد.
اصل بایت دقیقاً در object storage خصوصی نگهداری می‌شود و PostgreSQL مالکیت، وضعیت انتشار، checksum
و مشتق امن را تعیین می‌کند. هیچ object در MinIO عمومی نیست و اصل فایل از endpoint عمومی برگردانده
نمی‌شود.

مشتق‌ها محدود و ازپیش‌تعریف‌شده‌اند: `logo-small` حداکثر ۱۲۸×۱۲۸ و `logo-large` حداکثر
۵۱۲×۵۱۲ به WebP lossless؛ `cover-mobile` با عرض حداکثر ۹۶۰ و `cover-desktop` با عرض حداکثر
۱۹۲۰ به WebP با کیفیت ۹۲. نسبت حفظ می‌شود، upscale و crop انجام نمی‌شود. مسیر پایدار
`/v1/media/:mediaId` برای سازگاری مشتق بزرگ canonical را می‌دهد. resize دلخواه و انتخاب اصل مجاز نیست.

فایل ورودی حداکثر ۱۰ مگابایت و تصویر decodeشده حداکثر ۲۴ مگاپیکسل است. فقط JPEG، PNG و WebP
غیرمتحرک پذیرفته می‌شوند؛ MIME با signature واقعی تطبیق داده و decode کامل می‌شود. خطاهای حجم، ابعاد،
خرابی و قالب با پیام فارسی متمایز برمی‌گردند. محدودسازی نرخ برای فروشندهٔ احرازشده اعمال می‌شود.

## پیامدها

- پیش‌نویس فقط برای فروشندهٔ مالک خواندنی است؛ مشتق فروشگاه منتشرشده بدون نشست از API خوانده می‌شود.
- دسترسی عمومی فقط وقتی برقرار است که هم media در وضعیت عمومی باشد و هم یک فروشگاه منتشرشده به آن
  ارجاع دهد؛ بنابراین گذار انتشار از دید client اتمی است و شکست میانی باعث افشای رسانه نمی‌شود.
- اصل برای بازتولید آینده بدون افت تجمعی حفظ می‌شود و variantها یک‌بار ساخته و دوباره استفاده می‌شوند.
- ساخت مشتق نشان و جلد فعلاً همگام است؛ worker زمانی وارد مسیر می‌شود که بار چندتصویری یا p95 بالاتر از
  دو ثانیه آن را توجیه کند.
- CDN یا URL امضاشده بعد از اندازه‌گیری ترافیک قابل افزودن است، بدون تغییر interface client.

## بازنگری

اگر عبور رسانه از API گلوگاه اندازه‌گیری‌شده شود، کنترل crop به محصول افزوده شود یا سفر کالای فیزیکی
مجموعه variant متفاوتی بخواهد، این تصمیم باز می‌شود.
