# معماری

معماری و پشته فنی هنوز تصمیم نهایی نیستند. تصمیم‌ها به‌صورت ADR در `decisions/` ثبت می‌شوند و باید به Issue تصمیم مربوط لینک داشته باشند.

ترتیب مورد انتظار:

1. انتخاب پشته و شکل استقرار؛
2. تعیین مرز ماژول‌ها و مالکیت قراردادها؛
3. مدل داده و state machineهای حساس؛
4. baseline توسعه محلی، تست و CI؛
5. سپس scaffold کد.

تا پیش از این تصمیم‌ها، هیچ چارچوب، پایگاه داده یا سرویس ابری پیش‌فرض پروژه محسوب نمی‌شود.
